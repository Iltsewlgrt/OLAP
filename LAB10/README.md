# З10. Дашборд Metabase

LAB10 описывает дашборд продуктового магазина на ClickHouse. DuckDB в
дашборде не используется: источник всех карточек — база `olap_product`.

## Подключение Metabase

Запустите стенд:

```powershell
cd D:\Учеба\LAB1\Стенд
docker compose up -d
```

Откройте Metabase: <http://localhost:3000>.

Добавьте базу данных типа ClickHouse:

| Поле | Значение |
|---|---|
| Host | `clickhouse` для Metabase в Docker или `localhost` при подключении с хоста |
| Port | `8123` |
| Database name | `olap_product` |
| User | `lab` |
| Password | `lab123` |

Если Metabase предлагает отдельное поле протокола, выберите HTTP.

## Дашборд

Создайте дашборд `Продажи продуктового магазина` и добавьте карточки:

1. **Общий оборот** — карточка с числом из `dashboards/widget1_metric.sql`;
2. **Оборот по месяцам** — линейный график из `widget2_monthly.sql`;
3. **Топ-10 магазинов** — столбчатая диаграмма из `widget3_top10.sql`;
4. **Оборот по категориям** — столбчатая диаграмма из `widget4_categories.sql`.

SQL всех карточек сохранён в папке `dashboards`. В карточках используется
необязательная переменная `year`, чтобы один фильтр применялся ко всему
дашборду:

```sql
[[ AND d.year = {{year}} ]]
```

В Metabase создайте переменную типа **Number** с именем `year`, добавьте на
дашборд фильтр `Год` и свяжите его с переменной `year` каждой SQL-карточки.
Например, значение `2024` показывает только данные за 2024 год. Если фильтр
не задан, показываются все годы.

## Проверка

В карточке общего оборота без фильтра ожидается:

```text
10750467.76
```

Для проверки всех SQL без интерфейса Metabase можно выполнить:

```powershell
cd D:\Учеба\LAB10
py -3.13 etl\run_sql.py dashboards\validation.sql
```

Скриншот дашборда не обязателен: в репозитории сохранены описание, SQL
виджетов и инструкция подключения ClickHouse.
