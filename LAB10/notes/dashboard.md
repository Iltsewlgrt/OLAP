# Паспорт дашборда

## Источник

Все карточки используют ClickHouse `olap_product`. Источник правды для
оборота — детальная таблица `fact_sales`; график по месяцам использует
сводку `sales_by_store_month` из LAB9.

## Виджеты

| Виджет | Тип | Смысл |
|---|---|---|
| Общий оборот | Number | Сумма `total_amount` |
| Оборот по месяцам | Line chart | Динамика оборота по месяцам |
| Топ-10 магазинов | Bar chart | Магазины с наибольшим оборотом |
| Оборот по категориям | Bar chart | Сравнение категорий товаров |

## Фильтр

Фильтр дашборда `Год` имеет тип Number и передаёт значение в переменную
`year` каждой SQL-карточки. Все карточки поддерживают необязательное условие
`d.year = {{year}}` или `year = {{year}}`.

## Контрольная метрика

Без фильтра карточка «Общий оборот» должна показывать `10750467.76`. При
изменении фильтра все карточки пересчитываются для выбранного года.
