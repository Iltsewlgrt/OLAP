# Загрузка и проверки

`load_and_check.py` загружает CSV из `LAB3/data/raw/` в
`LAB3/warehouse.duckdb`. Сначала создаются таблицы из DDL, затем очищаются
старые строки в порядке «факты → измерения», после чего CSV загружаются в
порядке «измерения → факты».

При повторном запуске таблицы витрины удаляются в порядке внешних ключей и
создаются заново, поэтому продажи не дублируются. Транзакция фиксируется только
после успешных проверок качества:
NULL-ключи и суммы, отрицательные значения, даты до 1900 года, дубликаты
`sale_id` и сироты по `store_id`, `product_id`, `date_id`.

Запуск из папки `LAB5`:

```powershell
py -3.13 etl/load_and_check.py
```
