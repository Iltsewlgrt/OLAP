# З05. Загрузка и проверки

Лабораторная реализует повторяемый ELT-процесс для витрины LAB3.

- [etl/load_and_check.py](etl/load_and_check.py) загружает справочники до фактов
  и останавливается при ошибках качества;
- [etl/run_twice.ps1](etl/run_twice.ps1) выполняет два последовательных запуска;
- [etl/run_log.txt](etl/run_log.txt) содержит результаты двух запусков.

В обоих прогонах должны совпасть количество строк `fact_sales` и сумма
`total_amount`. Повторная загрузка безопасна: перед копированием CSV таблицы
витрины удаляются в порядке внешних ключей и создаются заново.
